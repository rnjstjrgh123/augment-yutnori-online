# 증강 윷놀이 온라인 v5

Minecraft가 아닌 웹 기반 온라인 윷놀이 프로젝트입니다. Node.js 18+ 환경에서 실행합니다.

## 실행
1. 압축을 풉니다.
2. `yutv2` 폴더에서 `npm install`을 실행합니다.
3. `npm start`를 실행합니다.
4. 브라우저에서 `http://localhost:3000`으로 접속합니다.

## 이번 버전
- 게임 시작 전에 각 플레이어가 증강을 직접 선택해야 합니다.
- 참가자 목록에 남은 말, 판 위의 말, 출발 전 말, 완주한 말을 표시합니다.
- 윷/모 추가 던지기 기회가 남아 있으면 기존 결과를 아직 사용하지 않고 다시 던질 수 있습니다.
- 여러 결과가 쌓이면 `윷 먼저 사용`, `개 먼저 사용`처럼 원하는 결과를 직접 골라 이동 순서를 정합니다.
- 말 이동 버튼을 누른 뒤 서버 응답이 실패하면 버튼이 다시 활성화됩니다.

배포는 저장소의 `package.json`, `server.js`, `public/index.html` 파일을 교체하고 Render에서 최신 커밋을 배포하세요.
