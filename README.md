# 증강 윷놀이 온라인 v1 (서버 연결 시작 프로젝트)

## 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 터미널 실행
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 열기
6. 같은 Wi-Fi의 다른 기기에서는 호스트 PC의 LAN IP로 `http://호스트IP:3000` 접속 가능(방화벽에서 3000 포트 허용 필요)

## 현재 실제로 동작하는 것
- Socket.IO 실시간 서버 연결
- 온라인 방 생성 및 공개 방 목록
- 방 코드로 참가(목록에서 참가 버튼)
- 방 비밀번호 확인(서버에서 검사)
- 참가자 목록 동기화 및 준비 상태
- 방장만 게임 시작
- 방장 추방 기능
- 서버에서 공유하는 윷 결과/턴/말 위치
- 간단한 말 출발, 선형 이동, 잡기, 완주, 업기 배수 표시

## 아직 구현/검증이 필요한 것
- 인터넷에 공개 배포된 서버(현재는 실행한 컴퓨터가 서버)
- 실제 정식 윷놀이 경로 분기/지름길/빽도 판정/업힌 말 묶음 이동의 완전한 규칙
- 윷가락 물리 시뮬레이션과 공정한 검증
- AI 전략, 증강 시스템, 친구 초대 링크, 계정/전적 저장
- 서버 재접속 복구, 보안 강화, 자동화 테스트
- Unity 네이티브 빌드 및 모바일 패키징

이것은 단순 정적 목업보다 한 단계 나아간 서버 연결형 웹 게임 시작 프로젝트입니다. 실제 공개 온라인 게임이 되려면 서버를 인터넷에 배포하고 게임 규칙을 추가 검증해야 합니다.
