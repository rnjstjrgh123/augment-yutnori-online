# 증강 윷놀이 온라인 v9

Node.js 18+ 기반 웹 멀티플레이 윷놀이입니다.

## 실행
1. 압축을 풉니다.
2. `yutv2` 폴더에서 `npm install`을 실행합니다.
3. `npm start`를 실행합니다.
4. 브라우저에서 `http://localhost:3000`으로 접속합니다.

## 이번 수정
- 방장이 대기실에서 `게임 시작`을 누른 뒤, 게임 화면 위에 TFT 스타일의 큰 증강 선택 모달이 표시됩니다.
- 모달에서 증강 카드 하나를 선택하고 `증강 선택 확정`을 눌러야 합니다.
- 모든 플레이어가 증강을 확정할 때까지 말판과 윷 던지기 화면은 숨겨집니다.
- 증강 선택 단계가 끝나면 모달이 사라지고 윷놀이 판이 나타납니다.
- 모바일 화면에서도 증강 카드가 2열로 보이고 작은 화면에 맞게 배치됩니다.
