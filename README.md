# 증강 윷놀이 온라인

Node.js + Express + Socket.IO 기반의 브라우저 멀티플레이 윷놀이 프로토타입입니다.

## 실행

1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 열기

Render 배포에서는 `PORT` 환경 변수를 자동 사용합니다. 정적 홈페이지는 `public/index.html`에서 제공됩니다.

## 이번 업데이트

- iOS Safari/모바일 화면 대응: 안전 영역, 터치 버튼, 반응형 게임판, Socket.IO 재연결 상태 표시
- `/` 경로에서 `public/index.html`을 명시적으로 제공
- 윷판의 외곽 경로와 대각선 지름길 선/노드를 끊김 없이 표시
- 도/개/걸/빽도 이동 후 남은 보너스가 없으면 다음 차례로 자동 전환
- 윷/모는 추가 던지기 기회를 부여
- 상대 말을 잡으면 추가 던지기 1회, `포획왕` 증강은 2회
- 게임 시작 시 플레이어별 증강 1개 부여
  - 행운의 윷: 윷/모가 나올 확률 증가
  - 포획왕: 상대 말을 잡으면 추가 던지기 2회
  - 수호 부적: 처음 당하는 포획 1회 방어
  - 질주: 출발한 말의 첫 양수 이동에 한 칸 추가

## 참고

현재는 멀티플레이 프로토타입입니다. 대각선 길은 보드에 연결해 표시하지만, 말 이동 규칙은 아직 외곽 진행도 기반의 간략 규칙이며, 정식 윷놀이의 모든 교차점 선택/지름길 이동/업기 규칙을 완전히 구현한 상태는 아닙니다. 방/게임 상태는 서버 메모리에 저장되므로 서버가 재시작되면 진행 중인 방이 초기화됩니다.
